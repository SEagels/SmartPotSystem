# Session: MQTT通配符匹配修复、在线状态重构、同步传感器轮询

## Decisions
- **在线状态基于遥测新鲜度（10分钟阈值）而非数据库 online 字段**: 数据库 seed 数据硬编码 online=True，无法反映真实连接状态
- **/sync-sensors 接口轮询等待设备响应（最多12秒），直接返回传感器数据**: 绕过 MQTT→WebSocket 不可靠链路，API 响应直接携带遥测数据
- **MQTT handler 查找从 dict.get 精确匹配改为 _match_topic 通配符匹配**: MQTT broker 路由消息后用精确 topic 回调，但 handler 注册用通配符 pattern，精确匹配永远失败

## Left Off
修复了 MQTT _on_message 的 topic 通配符匹配问题，添加了 _match_topic() 函数。用户反馈重启后不显示MQTT，需排查 broker 连接。
