# 03 — 传感器数据格式

## 1. 遥测数据 (Telemetry)

**MQTT Topic：** `smartpot/{device_id}/telemetry`
**上报频率：** 每 5 分钟（可配置）
**QoS：** 1

### 1.1 完整格式

```json
{
  "device_id": "SP1A2B3C",
  "timestamp": "2026-04-26T08:00:00Z",
  "sequence": 12841,
  "sensors": {
    "temperature": 25.3,
    "humidity": 65.2,
    "soil_moisture": 42.8,
    "light_intensity": 850.0
  },
  "actuators": {
    "pump_running": false,
    "led_on": false,
    "water_tank_level_pct": 68.0
  },
  "system": {
    "wifi_rssi": -48,
    "free_heap_kb": 256,
    "uptime_s": 86400,
    "firmware_version": "v1.2.3"
  }
}
```

### 1.2 字段说明

| 路径 | 类型 | 单位 | 范围 | 说明 |
|------|------|------|------|------|
| `device_id` | string | — | `SP` + 6 位 hex | 设备唯一标识 |
| `timestamp` | string(ISO8601) | — | UTC | 采集时间戳 |
| `sequence` | int | — | 0 ~ 2^31-1 | 自增序列号，重启归零 |
| `sensors.temperature` | float | °C | -40 ~ 85 | 空气温度 (DHT22) |
| `sensors.humidity` | float | %RH | 0 ~ 100 | 空气相对湿度 (DHT22) |
| `sensors.soil_moisture` | float | % | 0 ~ 100 | 基质/土壤湿度 (已标定) |
| `sensors.light_intensity` | float | lux | 0 ~ 65535 | 环境光照强度 (BH1750) |
| `actuators.pump_running` | bool | — | — | 水泵当前是否运行 |
| `actuators.led_on` | bool | — | — | 补光灯当前是否亮起 |
| `actuators.water_tank_level_pct` | float | % | 0 ~ 100 | 水箱余量百分比 |
| `system.wifi_rssi` | int | dBm | -100 ~ 0 | WiFi 信号强度 |
| `system.free_heap_kb` | int | KB | — | 可用内存 |
| `system.uptime_s` | int | 秒 | — | 设备运行时长 |
| `system.firmware_version` | string | — | — | 当前固件版本 |

## 3. 阈值配置 (云端下发)

云端针对不同植物品种维护阈值表，通过 `command/config` 下发给设备：

```json
{
  "plant_type": "monstera_deliciosa",
  "thresholds": {
    "temperature": {"min": 15.0, "max": 32.0},
    "humidity": {"min": 40.0, "max": 85.0},
    "soil_moisture": {"min": 30.0, "max": 70.0},
    "light_intensity": {"min": 500.0, "max": 25000.0}
  },
  "watering": {
    "trigger_soil_moisture": 25.0,
    "default_duration_ms": 8000,
    "cooldown_minutes": 120
  }
}
```

## 4. 图片元数据

图片本身通过 HTTPS 上传，上传成功后通过 MQTT 通知附带以下元数据：

```json
{
  "image_id": "IMG-20260426-080001-SP1A2B3C",
  "device_id": "SP1A2B3C",
  "timestamp": "2026-04-26T08:00:01Z",
  "photo_index": 1,
  "burst_total": 3,
  "quality_score": 0.92,
  "light_condition": "led_fill",
  "resolution": "1600x1200",
  "file_size_bytes": 245760,
  "format": "jpg"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `quality_score` | float | 端侧拉普拉斯清晰度评分，范围 0~1 |
| `light_condition` | string | `natural` 自然光 / `led_fill` 补光 / `low_light` 弱光 |
| `photo_index` | int | 连拍组中的序号 |
| `burst_total` | int | 本次连拍总数 |
