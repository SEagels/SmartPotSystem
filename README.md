# SmartPotSystem — 具有植株病害检测功能的智能花盆系统

## 项目概述

基于 ESP32-S3 的端—云协同智能花盆系统，集成环境感知、自动补水、图像采集、YOLOv11 云端病害识别与 Android 用户端，实现"看得见状态、管得住养护、提前预警风险"的闭环管理。

## 技术栈

| 层级 | 技术选型 |
|------|---------|
| 硬件端 | ESP32-S3, DHT22, 土壤湿度传感器, BH1750 光照传感器, OV2640 摄像头, 微型水泵 |
| 通信协议 | MQTT (硬件↔云端), HTTP REST (App↔云端), HTTPS 图片上传 |
| 云端后端 | Python/FastAPI, PostgreSQL + TimescaleDB, Redis, MinIO (图片存储) |
| AI 模型 | YOLOv11 植株病害检测, LLM 养护策略推荐 |
| 用户端 | Android (Kotlin), 仅与云端 API 交互 |

## 核心功能清单

1. **环境感知** — 温湿度、土壤湿度、光照周期性采集上报
2. **自动补水** — 基于品种-基质湿度阈值的自动补水 + 云端手动触发
3. **定时拍照** — 每日 3 次定时拍照，连拍选优，补光辅助
4. **病害识别** — 云端 YOLOv11 推理，输出类别/置信度/定位，准确率 ≥ 80%
5. **告警推送** — 病害检测后实时通知用户端
6. **养护建议** — 结合历史数据与 AI 大模型生成个性化浇水策略
7. **数据可视化** — 历史曲线、统计摘要、日报/周报
8. **远程控制** — 手动补水、拍照触发、参数配置
